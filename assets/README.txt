壁紙スケジューラ
================

指定した時刻に Windows の壁紙を自動で切り替えるアプリです。
「朝はこの画像、夜はこの画像」のように、毎日決まった時刻に壁紙が変わります。


■ 動作環境

  Windows 10 / Windows 11
  （追加のインストールは不要です）


■ はじめかた

  1. ZIP を右クリック →「すべて展開」で、好きな場所に展開します。
     （例: ドキュメント\WallpaperScheduler）
  2. WallpaperScheduler.exe をダブルクリックして起動します。
  3. 設定画面の「追加」から、切り替える時刻と画像を登録します。
     画像を画面にドラッグ＆ドロップしても登録できます。
     画像の代わりにフォルダを選ぶと、その中からランダムに表示します。

  変更はその場で保存・反映されます。
  画面を閉じても、アプリはタスクトレイ（画面右下）で動き続けます。


■ 初回起動時に「Windows によって PC が保護されました」と表示されたら

  インターネットから入手した、署名のないアプリで表示される確認画面です。
  「詳細情報」をクリックし、「実行」を押すと起動できます。


■ 使い方のヒント

  ・タスクトレイのアイコンをクリックすると設定画面が開きます。
  ・右クリックで「今すぐ適用」「自動切り替え（オン/オフ）」「終了」などが選べます。
  ・最初の時刻より前（深夜など）は、前日の最後の壁紙が表示されます。
  ・画像の代わりにフォルダを登録すると、その時間帯が始まるたびに
    フォルダ内の画像からランダムに選びます。
    フォルダの画像を全部 1 回ずつ表示し終えるまで、同じ画像は選びません。
    追加・編集の画面の「フォルダから選ぶ」か、フォルダをドラッグ＆ドロップで登録できます。
  ・最初に表示する画像が気に入らないときは、登録画面の「別の画像にする」で選び直せます。
  ・表示中の画像を変えたいときは、設定画面のシャッフルボタン（「今すぐ適用」の右）か、
    タスクトレイの右クリック →「別の画像にする」で選び直せます。
  ・「Windows の起動時に開始」をオンにすると、PC の起動時に自動で動き始めます。
    このときは画面を出さずに、タスクトレイで静かに動きます。
    （exe をダブルクリックして起動したときは、設定画面が開きます）
  ・exe を別の場所に移動した場合は、新しい場所の exe を一度起動してください。
    自動起動の登録先が自動で新しい場所に更新されます。
  ・お試しで展開したフォルダーで「Windows の起動時に開始」をオンにした場合、
    そのフォルダーを削除する前に、普段使う場所の exe を起動しておいてください。


■ 新しいバージョンに更新するときは

  タスクトレイのアイコンを右クリック →「終了」してから、今使っているフォルダーの
  WallpaperScheduler.exe を新しい exe で上書きしてください。設定も自動起動もそのまま引き継がれます。

  新しいバージョンを別のフォルダーに展開した場合は、自動起動が古い exe を指したままになります。
  新しい exe を起動して、設定画面の「Windows の起動時に開始」のスイッチを
  一度オフにしてから、もう一度オンにしてください。そのあと古いフォルダーは削除して構いません。


■ PC を起動しても自動で立ち上がらないときは

  Windows の設定で、自動起動がオフになっていることがあります。
  その場合は、アプリの設定画面に「Windows の設定で自動起動がオフになっています」と
  表示されます。次のどちらかで、オンに戻してください。

    ・アプリの設定画面で「Windows の起動時に開始」のスイッチをオンにする
    ・Windows の 設定 → アプリ → スタートアップ で「壁紙スケジューラ」をオンにする


■ タスクトレイにアイコンが見当たらないときは

  Windows 11 では、新しいアプリのアイコンは最初、タスクバー右側の「^」の中に
  隠れています。常に表示するには、次のように設定します。

    1. タスクバーの何もないところを右クリック →「タスクバーの設定」
    2. 「その他のシステム トレイ アイコン」を開く
    3. 「壁紙スケジューラ」をオンにする

  （Windows 10 の場合は「タスク バーに表示するアイコンを選択します」から設定します）

■ アンインストール

  1. 設定画面で「Windows の起動時に開始」をオフにします。
  2. タスクトレイのアイコンを右クリック →「終了」を選びます。
  3. 展開したフォルダーを削除します。
  4. 設定も消す場合は、次のフォルダーを削除します。
       %APPDATA%\WallpaperScheduler
     （エクスプローラーのアドレス欄に貼り付けると開けます）

  インストーラーは使っていないため、手順 1 で自動起動をオフにしておけば
  アプリの痕跡は残りません（壁紙そのものは最後に設定されたまま残ります）。
